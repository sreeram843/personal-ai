# Capacitor native apps

CurieAI ships as a cross-platform mobile app via [Capacitor](https://capacitorjs.com/). The React/Vite web build is copied into native iOS and Android shells.

## Prerequisites

- Node.js 20+
- Xcode 26+ (iOS simulators use **iPhone 17** family)
- Android Studio (Android)
- A reachable backend URL for device builds

## Configure API URL

Capacitor WebViews cannot rely on same-origin API routing. Set the backend URL at build time:

```bash
cp .env.capacitor.example .env.capacitor.local
# edit VITE_API_BASE_URL to your deployed API, e.g. https://app.cura-i.com
export $(grep -v '^#' .env.capacitor.local | xargs)
npm run cap:sync
```

For local device testing against Docker on your Mac:

```bash
export VITE_API_BASE_URL=http://192.168.10.1:8000   # or your Mac's LAN IP
npm run build:capacitor && npx cap sync ios
```

For iOS Simulator with local Docker:

```bash
VITE_API_BASE_URL=http://localhost:8000 npm run build:capacitor
npx cap sync ios
npx cap run ios --target-name "iPhone 17" --no-sync
```

For iOS Simulator against **production** (recommended — avoids CORS issues):

```bash
./scripts/ios_simulator_smoke.sh --cloud --target "iPhone 17"
```

This loads `https://app.cura-i.com` inside the native WebView (same-origin API). Google Sign-In uses the web flow.

For a **bundled** native build that calls a remote API, add Capacitor origins to server CORS:

```bash
# .env.cloud on the VM
CORS_ORIGINS=https://app.cura-i.com,capacitor://localhost,ionic://localhost
```

Ensure `CORS_ORIGINS` in `.env.remote` (local Docker) includes `capacitor://localhost,ionic://localhost`.

## Build and open native projects

```bash
npm run cap:sync      # build web assets + copy into ios/ and android/
npm run cap:ios       # open Xcode
npm run cap:android   # open Android Studio
```

## iOS Simulator testing

**Requires full Xcode** (App Store), not just Command Line Tools:

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -license accept
```

```bash
# From repo root — builds, syncs, launches simulator
./scripts/ios_simulator_smoke.sh --target "iPhone 17"

./scripts/ios_simulator_smoke.sh --list
```

| Environment | API URL |
|-------------|---------|
| iOS Simulator | `http://localhost:8000` |
| Android Emulator | `http://10.0.2.2:8000` |
| Physical device on LAN | `http://<your-mac-ip>:8000` |
| Production | `https://app.cura-i.com` (set in `.env.capacitor.local`) |

**Auth in simulator:** With `AUTH_DISABLED=true`, the app skips login. For Google Sign-In, register bundle ID `com.curai.app` in Google Cloud Console.

## Mobile UI (web + native shell)

| Feature | Location |
|---------|----------|
| Navigation drawer | Hamburger in header (`< md` breakpoints) |
| Theme toggle | Account menu → Light/Dark (above Log out) |
| About | Account menu |
| Response time | Below each assistant message (copy / feedback row) |
| Share / Settings header buttons | Removed (theme moved to account menu) |
| Ready status chip | Removed (thinking logo only while responding) |

Scroll: message list uses `.message-log` with touch scrolling; body scroll locked on native (`html.capacitor-native`).

## Google Sign-In on native

- Web builds use `@react-oauth/google`.
- iOS/Android use `@capgo/capacitor-social-login` with the same `GOOGLE_CLIENT_ID` web client ID.
- Register iOS bundle ID `com.curai.app` and Android SHA-1 in Google Cloud Console.

## Tests

```bash
npm run test:unit        # API URL + platform helpers
npm run test:capacitor   # mobile drawer, user menu theme toggle
npm run test:e2e         # full Playwright suite
```

## Project layout

| Path | Purpose |
|------|---------|
| `capacitor.config.ts` | App ID, web dir, keyboard resize |
| `ios/` | Xcode project (generated by Capacitor) |
| `android/` | Android Studio project (generated by Capacitor) |
| `src/platform/` | Native shell detection and API URL resolution |
| `src/auth/googleSignIn.ts` | Native Google sign-in bridge |
